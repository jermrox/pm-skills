Skill catalog

Click any skill to add it to the agent you are composing. Hue marks its lifecycle phase; foundation, utility, and tool skills sit outside the diamonds.

Agents

The six sub-agents that ship with pm-skills. Each runs in its own context window with a fixed tool budget, and none may spawn another agent unless allowlisted in agents/_chain-permitted.yaml.

Workflows

Ordered multi-skill playbooks. Copy a run prompt to walk one step by step with a go/no-go pause between stages.

FigJam Studio

Turn a skill, agent, or workflow into a board. Paste the prompt into a session with the Figma MCP server connected, or take the mermaid skeleton straight into FigJam.
